# HRFlow — Plateforme RH SaaS

Plateforme de gestion RH pour les PME françaises.

## Stack

- Frontend : React 18
- Backend : Node.js / Express
- BDD : PostgreSQL + Redis
- Infra : OVH VPS + Nginx

## Installation

```bash
npm install
cp .env.example .env  # remplir les valeurs
npm run dev
```
